# LORE — where the bodies are buried

*Surprises, not decisions. What will bite you. One line each, dated.*

- **The sentinel bug (session 1):** `d = -1` made one variable do two jobs (in-spell boolean + counter). Both first-passage bugs lived in the seam. Rule: when the measurement window and the thing being counted can diverge, they get separate variables.
- **The accidentally-unbiased estimator (session 1):** three interacting bugs cancelled *exactly* — but only because spell lengths were geometric. "Output matches theory" is necessary, not sufficient; trace small cases by hand.
- **Wrong guesses are curriculum (throughout):** 5 vs 6.67 days; 7% vs 9.9%; column-sums vs true π. The gap between gut and truth is where the learning was. Always predict before running.
- **Ross hides load-bearing walls in "let"s (Bonus-Malus, 3 weeks):** the posited table s(i,k) was defined as if it were notation. Protocol: audit the "let"s, sort nature vs posited, before reading any formula.
- **Definition vs theorem (Bonus-Malus):** reading a definition while hunting for a theorem's insight = guaranteed mugging. Check the verbs ("let/denote/suppose" vs "then/it can be shown") before hunting for cargo.
- **The dummy-variable ambush (twice):** k = claim counts, then k = waypoint states. Bound variables are renameable scaffolding, gone by the end. If asking "is k an input or output" — it's neither, it's the loop variable.
- **Scalar trap in CK:** P¹⁰ᵢⱼ ≠ (P⁵ᵢⱼ)². Matrices multiply; entries don't. The sum over waypoints IS the matrix product.
- **"Recurrent" means RETURN, not STAY (4.3):** absorbing is the corner case of recurrent, not its definition. Occupancy without residence.
- **Certain return + infinite expected return time coexist (fair walk):** infinite mean = fat tail, not infinite outcomes. The mean is a census rare giants can bankrupt (St Petersburg). Directly relevant to drawdown/recovery times in markets.
- **Frozen-dialect vocabulary:** "communicates" = dialogue (1950s sense), not press release. "Expectation" — nobody expects 3.5 from a die. When a term fights its everyday meaning, check the coinage-era meaning.
- **Format lore (meta, the big one):** three consecutive text-decoding exchanges without running code = energy collapse incoming. Build first; Ross as audit. Either party can pull the cord.
- **Notebook-build day (today):** my own census cell double-counted the initial visit (n=0 term already includes day zero — the day-zero genre strikes again, in MY code this time) and comb(2n,n) overflows floats by n≈500; ratio recursion dodges it.
